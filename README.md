# RenalTech Solutions — production website

Self-hosted marketing website for RenalTrack. Includes Tailwind CSS 4.3.3,
daisyUI 5.7.50 and Vite 8.3.5, resolved from npm latest on 25 October 2026.
Exact dependency versions and package-lock.json are included for repeatable builds.

## Go live with GitHub + Vercel (recommended)
1. Create an empty GitHub repository (e.g. `renaltech-solutions`), then in this folder:

       git init -b main
       git add .
       git commit -m "RenalTech Solutions website"
       git remote add origin https://github.com/<your-username>/renaltech-solutions.git
       git push -u origin main

2. Go to vercel.com > Add New > Project > import the repository. Vercel reads
   `vercel.json` (build `npm run build`, output `dist`). Click Deploy. Every
   later `git push` to `main` redeploys automatically.
3. Add your domain under Project > Settings > Domains and follow the DNS steps.

Alternative, free GitHub Pages: repo Settings > Pages > Source = "GitHub Actions".
`.github/workflows/deploy-pages.yml` then builds and publishes on every push to
`main`. (Use either Vercel or Pages, not both.)

## Quick deployment (no Node.js needed on hosting)
Upload the CONTENTS of dist/ into your website document root (for example,
cPanel public_html or your IIS/Nginx website directory). Keep assets/ beside
index.html. Use a web server; do not open index.html through file://.
Use HTTPS on your host. No Docker, database, API keys or paid CDN is required.
Relative build paths support root or subdirectory hosting.

## Edit and build on Windows
Install Node.js 24 LTS (or a supported Node release >=22.12), then open PowerShell
in this extracted folder:

    npm ci
    npm run dev

Open the local URL printed by Vite. For a production build:

    npm run build
    npm run preview

Upload the new dist/ contents after each build. npm run dev / preview are local
checks, not your production web server. node_modules is intentionally excluded.

## Files to customize
- index.html — page copy, navigation, Facebook links, FAQ, video markup.
- src/styles.css — Tailwind imports, daisyUI custom renaltech theme, layout rules.
- src/main.js — interactive feature tabs and walkthrough play action.
- public/assets/ — logo, fictional-data screenshots and promotional MP4.
- vite.config.js — Vite + official Tailwind plugin; relative deployment base.
- dist/ — precompiled deployable website, generated by npm run build.

DaisyUI provides buttons, tabs, badge, and FAQ collapse components. Tailwind
utilities compose the layout through @apply. No runtime Tailwind browser CDN.
The terminal.local allowed host entry supports the authoring preview only;
remove it if not needed. It does not configure your production domain.

## Hosting examples
cPanel/Apache: upload dist contents to public_html or a dedicated subdirectory.
IIS: enable Static Content, create a website pointed to the uploaded dist files,
set index.html as a default document, and bind your domain with an HTTPS certificate.
Nginx: point root at dist and serve index.html; no SPA catch-all is required.
Ensure .mp4 is served as video/mp4 with byte-range support for seeking.
